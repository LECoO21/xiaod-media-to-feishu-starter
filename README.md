# 小D-链接转录助手・小白版 v2

把公开音视频、本地媒体、字幕、逐字稿或用户有权访问的飞书内容整理成分享式中文长稿，完成本地质检、飞书知识库交付、访问验证和中间文件清理。

v2 是一个脱敏的完整 Hermes Profile 分发包，不再只是单独安装 Skill。安装后会检查飞书机器人、消息网关、聊天配对、用户 CLI 和目标知识库，避免“显示安装成功但不能聊天或没有入库”。

## 安装前准备

- Apple Silicon Mac；
- Hermes Agent 0.20.0 或更高版本；
- `lark-cli` 飞书 CLI 1.0.83 或更高版本。

## 安装

下载并解压最新 Release，双击 `install.command`。也可以在目录中运行：

```bash
python3 scripts/install.py
```

安装完成后运行：

```bash
xiaod-setup
```

向导会依次完成：

1. 配置使用者自己的模型服务；
2. 扫码创建或绑定飞书机器人；
3. 将机器人名称改为“小D-链接转录助手”并发布；
4. 安装并启动消息网关；
5. 完成飞书私聊配对；
6. 完成飞书 CLI 用户授权；
7. 创建或验证“音视频转录整理”知识库；
8. 运行端到端部署检查。

全部通过后，在飞书里直接与“小D-链接转录助手”聊天。也可以运行 `xiaod chat`。

## 验收原则

`xiaod-doctor` 只有在以下项目全部真实通过时才返回成功：

- 完整 Profile 已安装；
- 模型服务已配置；
- 媒体处理工具可用；
- 飞书机器人已配置并完成改名确认；
- Hermes 消息网关正在运行；
- 至少一个飞书用户已经配对；
- 飞书 CLI 的用户身份有效；
- 目标知识库名称唯一且当前用户可访问。

每次交付仍会单独验证文档确实进入知识库、目录可回读且链接可访问。验证失败时保留本地文件，不报告完成。

## 安全

仓库只包含变量名称和通用流程，不包含任何真实 API Key、Token、Cookie、账号、应用标识、知识库标识、授权链接或个人绝对路径。

模型凭据由 Hermes 保存；飞书机器人凭据由 Hermes 扫码部署流程保存在本机 Profile 的 `.env`；飞书用户授权由 `lark-cli` 保存在本机。上述文件和运行状态均不进入 Git。

## 版本保留

- `v1.0.0` Release 和 `xiaod-media-to-feishu-starter/` 目录保持原样；
- 仓库根目录是 v2 完整 Profile 分发包；
- v2 更新可使用 `hermes profile update media-transcriber`，本机凭据、配对、会话和知识库配置不会被覆盖。
